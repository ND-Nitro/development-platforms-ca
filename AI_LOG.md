# AI Usage Log

### ArticleHub | Development Platforms Course Assignment

**Project:** ArticleHub  
**Assignment:** Option 2 – Frontend with Supabase  
**AI Tool:** ChatGPT by OpenAI

---

## 1. Purpose of AI Usage

I used AI as a learning resource and development guide throughout the project.

I already had experience with React, JavaScript, Tailwind CSS, and Git from previous projects.

Supabase was new to me, especially authentication, database integration, and Row Level Security (RLS).

AI provided guidance and explanations that helped me better understand these technologies.

---

## 2. Project Setup

I used AI guidance while setting up the React application with Vite, Tailwind CSS, and Supabase.

AI explained how environment variables work and how they connect the frontend to Supabase.

I followed the guidance, configured the project, and tested the setup locally.

---

## 3. Authentication

I worked on implementing authentication using Supabase, with AI providing guidance and explanations throughout the process.

This included:

- User registration
- Email confirmation
- Login and logout
- Authentication state management
- Protected routes

AI provided code examples and explained how the authentication process works.

I reviewed the implementation and tested the authentication functionality.

I also made decisions about the user experience, including displaying a successful login message before redirecting users.

---

## 4. Database Integration

I integrated Supabase with the React application using AI guidance to understand database queries and operations.

AI explained how to fetch articles and insert new articles into the database.

I tested article creation and verified that articles were stored correctly.

I also confirmed that articles could be viewed without logging in.

---

## 5. Row Level Security (RLS)

Row Level Security was one of the most unfamiliar parts of the project.

I used AI to understand how Supabase policies control database access.

AI guided me through the process of configuring policies for public article reading and authenticated article creation.

I tested the database security and verified that unauthenticated users could not create articles.

---

## 6. Troubleshooting

During development, I used AI as a troubleshooting guide.

This included:

- Authentication state updates
- Login redirects
- Supabase email confirmation
- Environment variable configuration
- Deployment problems

I used browser developer tools and error messages to investigate issues.

AI provided explanations and suggestions that I used when troubleshooting.

---

## 7. Deployment

I deployed the application using Vercel, with AI providing guidance during the configuration process.

This included connecting the GitHub repository, selecting the production branch, and configuring environment variables.

During deployment, the application initially displayed a blank page.

I investigated the browser console and discovered that the Supabase URL was missing.

AI guided me through checking the environment variables and correcting the configuration.

---

## 8. Responsibility and Learning

I tested the application locally, checked the Supabase database, and verified the authentication and security functionality.

AI was used as a guide and learning resource throughout the development process.

I remained responsible for the project decisions, configuration, testing, and final submission.

The project allowed me to build on my existing frontend skills while learning Supabase authentication, database operations, Row Level Security, and deployment.

---

## Summary

AI was primarily used for guidance, explanations, code examples, and troubleshooting.

The project was developed through practical implementation, testing, and applying knowledge gained during the development process.
